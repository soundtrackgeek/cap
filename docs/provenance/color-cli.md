# color-cli rendering provenance

`cap-effects` ports the pure rendering data and equations from the read-only
`color-cli` checkout at:

- repository: `C:\_code\deepseek_test\color-cli`
- commit: `c813f12f8578283b68fa124944c0078f15ccdec3`
- source file: `colorcli.py`
- inspected version: `1.0.0`

The port covers the eight `PALETTES` arrays, `lerp_rgb`, `palette_color`, the
five `pick_color` gradient modes (`text`, `line`, `vertical`, `diagonal`, and
`rainbow`), smoothstep reveal intensity, and shimmer's quadratic white falloff.
`tests/fixtures/color-cli/reference.json` records small outputs generated by
calling those original pure Python functions at the pinned revision. Rust uses
Python-compatible ties-to-even channel rounding; any remaining difference is
limited to floating-point representation (the acceptance tolerance is one
channel value).

The upstream checkout was not modified. `cap` contains no Python runtime
dependency and does not shell out to `colorcli.py`.
